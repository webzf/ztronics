# ESP32 800×480 Display Selector

An **800×480 display** puts different demands on an ESP32 project than a small SPI screen. Interface choice, framebuffer memory, GPIO usage and touch hardware can all affect the board you should choose.

Use the Embedded Nerd selector to filter compatible hardware and then compare the resulting boards and display modules.

<a class="btn btn--primary" href="/tools/esp32-touchscreen-selector/#preset=large-display">Open the 800×480 hardware selector</a>

## What matters with an 800×480 ESP32 display?

- Display interface and controller
- PSRAM for larger graphical buffers when required by the application
- GPIO availability for RGB or parallel interfaces
- Touch controller and bus
- LVGL or other graphics framework requirements
- USB, storage and battery features needed by the project

The selector is designed to narrow the search; exact electrical and driver compatibility must still be checked.
