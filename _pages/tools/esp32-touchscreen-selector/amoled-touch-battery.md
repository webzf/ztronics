# ESP32 AMOLED Touchscreen Battery Selector

For a compact **ESP32 AMOLED touchscreen with battery support**, several hardware requirements have to line up: AMOLED display, touch controller, touch bus, power hardware and the ESP32 family.

Use the Embedded Nerd selector to compare catalog hardware against those requirements instead of choosing from display size alone.

<a class="btn btn--primary" href="/tools/esp32-touchscreen-selector/#preset=s3-amoled-touch">Open the AMOLED + Touch + Battery selector</a>

## Important compatibility checks

- AMOLED interface and controller
- Capacitive touch controller and I²C/SPI connection
- Battery charging and power-management hardware
- ESP32 memory and available GPIO
- Driver and LVGL requirements if the project uses a graphical interface

The preset is a starting point, not a guarantee of compatibility. Verify the manufacturer's documentation before purchase.
