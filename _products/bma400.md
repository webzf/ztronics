The **BMA400** is an ultra-low power 3-axis accelerometer from **Bosch Sensortec**, designed for battery-powered applications where motion sensing and long battery life are important.

The sensor provides acceleration measurements along the X, Y and Z axes with selectable measurement ranges from **±2g to ±16g** and a digital resolution of **12 bits**.

Unlike a traditional accelerometer that simply provides raw acceleration measurements, the BMA400 includes several built-in motion-processing features. These include step counting, activity recognition, orientation detection, tap and double-tap detection, programmable interrupts and a 1 KB FIFO.

The sensor supports both **I2C and SPI**, making it suitable for Arduino, ESP32 and other embedded systems.

* 3-axis accelerometer

## Accelerometer

The BMA400 provides acceleration measurements along three axes:

* X
* Y
* Z

Four selectable measurement ranges are available:

* ±2g
* ±4g
* ±8g
* ±16g

The lower ±2g range is useful for applications such as tilt and orientation sensing where acceleration levels remain relatively small.

Higher ranges can be selected when the application involves stronger movement, vibration or impacts. :contentReference[oaicite:3]{index=3}

## Low-Power Operation

Low power consumption is one of the main characteristics of the BMA400.

Bosch specifies typical current consumption of approximately **5.8 µA** for a typical use case and **3.5 µA** in the low-power use case. Maximum-performance continuous measurement is specified at approximately **14.5 µA**.

The sensor also provides an ultra-low-power automatic wake-up mode. :contentReference[oaicite:4]{index=4}

This makes the BMA400 particularly useful for:

* Battery-powered sensors
* Wearable electronics
* IoT devices
* Security sensors
* Asset tracking
* Portable electronics
* Smart-home devices

---

## I2C Communication

The BMA400 supports digital communication through **I2C** as well as SPI.

In I2C mode, the sensor can use one of two addresses:

* `0x14`
* `0x15`

The address depends on the configuration of the SDO/address-select pin.

I2C makes the BMA400 particularly convenient for ESP32 and Arduino projects because other peripherals can share the same bus.

For example, an ESP32 can communicate with a BMA400 and an SSD1306 OLED using the same SDA and SCL lines, provided that the devices use different I2C addresses.

---

## SPI Communication

The BMA400 also supports SPI communication.

SPI can be useful when higher bus performance or a dedicated sensor interface is required.

Bosch's design guidance notes that SPI can also be advantageous in ultra-low-power designs because the pull-up resistors required by I2C consume additional current. :contentReference[oaicite:5]{index=5}

## Motion Detection

The BMA400 includes hardware functionality for detecting motion-related events.

Programmable interrupts can be configured to react to acceleration thresholds and other conditions.

This allows the sensor to notify the host microcontroller when a relevant event occurs instead of requiring the microcontroller to continuously process every measurement.

This is particularly useful in low-power applications where the microcontroller can remain in a sleep state until the accelerometer detects movement.

---

## Step Counter

The BMA400 includes an integrated **step counter**.

The feature is designed to perform step detection inside the sensor, reducing the amount of processing required by the host microcontroller.

This makes the BMA400 suitable for:

* Activity trackers
* Wearable devices
* Step counters
* Fitness projects
* Motion-aware IoT devices

Bosch specifies step-counting functionality with an overall device current consumption below approximately 4 µA. :contentReference[oaicite:6]{index=6}

---

## Activity Recognition

The BMA400 includes built-in activity recognition capable of distinguishing between:

* Walking
* Running
* Standing still

This allows applications to obtain higher-level activity information without having to implement the complete recognition algorithm on the host microcontroller.

---

## Orientation Detection

The sensor includes built-in orientation detection.

This can be useful for applications that need to determine how a device is positioned without continuously processing the raw acceleration data on the ESP32 or Arduino.

Typical applications include:

* Wearables
* User interfaces
* Portable devices
* Orientation-controlled systems
* Motion-controlled electronics

---

## Tap and Double-Tap Detection

The BMA400 can detect both **single taps and double taps**.

The feature can be combined with the interrupt pins to create interfaces where a physical tap on the device triggers an action.

For example, a battery-powered ESP32 device could remain in a low-power state and wake when a tap is detected.

---

## Interrupts

The BMA400 provides two programmable interrupt outputs:

* INT1
* INT2

These can be mapped to different sensor events.

Possible uses include:

* Motion detection
* Wake-up
* Orientation changes
* Tap detection
* Double-tap detection
* Step detection
* Data-ready events
* FIFO events

The interrupt system is particularly useful when the BMA400 is used together with a microcontroller operating in a low-power sleep mode. :contentReference[oaicite:7]{index=7}

---

## FIFO Buffer

The BMA400 includes a **1 KB FIFO buffer**.

The FIFO can store sensor data inside the accelerometer before it is read by the host microcontroller.

This can reduce the frequency with which the microcontroller needs to communicate with the sensor and can be useful for applications that process acceleration data in batches.

---

## Output Data Rate

The BMA400 supports output data rates from:

* 12.5 Hz
* 25 Hz
* 50 Hz
* 100 Hz
* 200 Hz
* 400 Hz
* 800 Hz

The appropriate setting depends on the application.

Lower output data rates can reduce the amount of data that needs to be processed, while higher rates are useful when faster motion needs to be captured. :contentReference[oaicite:8]{index=8}

## BMA400 with ESP32

The BMA400 works particularly well with the ESP32 because both devices support I2C and SPI communication.

A typical project can connect the BMA400 to an **[ESP32 DevKit V1](/products/esp32-devkit/)** and use the sensor as a low-power motion detector.

The ESP32 can process the sensor data locally or use its Wi-Fi and Bluetooth connectivity to transmit motion information.

A particularly interesting combination is the BMA400's motion interrupts with the ESP32's deep-sleep functionality.

The BMA400 can detect movement while the ESP32 remains in a low-power state and then generate an interrupt to wake the microcontroller.

Because both devices can communicate through I2C, they can share the same bus when their addresses do not conflict.

A project can display:

* X acceleration

## Power Requirements

The BMA400 supports a wide supply-voltage range.

The main sensor supply, **VDD**, supports approximately:

**1.72 V to 3.6 V**

The digital I/O supply, **VDDIO**, supports:

**1.2 V to 3.6 V**. :contentReference[oaicite:9]{index=9}

This makes the device suitable for low-voltage microcontroller systems.

However, breakout boards can include additional circuitry such as voltage regulators and level-shifting components.

Always check the specifications of the specific BMA400 breakout board before connecting it to a development board.

---

## Package and Size

The BMA400 is supplied in a compact **12-pin LGA package** measuring approximately:

**2 mm × 2 mm × 0.95 mm**

Its small footprint makes it suitable for compact wearable and IoT designs. :contentReference[oaicite:10]{index=10}

For breadboard prototyping, a breakout board is recommended because the bare sensor is not practical to connect directly to standard jumper wires.

## BMA400 vs MPU6050

The BMA400 and MPU6050 are both popular motion sensors, but they target different requirements.

The BMA400 provides:

* 3-axis acceleration
* Very low power consumption
* Motion-processing features
* Step counting
* Activity recognition
* Orientation detection
* Tap detection

The MPU6050 provides:

* 3-axis acceleration
* 3-axis gyroscope
* 6-axis motion sensing
* Integrated temperature sensor
* Digital Motion Processor

If a project requires a gyroscope, the MPU6050 is the more appropriate choice.

If the project primarily requires acceleration, motion detection and low-power operation, the BMA400 is a strong alternative.
