The **BME280** is a digital environmental sensor from **Bosch Sensortec** that combines **temperature, relative humidity, and barometric pressure measurement** in a single device.

It is widely used in Arduino, ESP32, ESP8266, Raspberry Pi, and other embedded systems where environmental measurements are required.

The sensor supports both **I²C and SPI communication**, making it suitable for a wide range of microcontroller projects.

## BME280 Features

- Temperature, humidity, and atmospheric pressure measurement
- Digital sensor interface
- I²C and SPI communication
- I²C addresses: `0x76` and `0x77`
- Temperature operating range: `-40°C to +85°C`
- Pressure measurement range: `300 to 1100 hPa`
- Relative humidity accuracy: approximately `±3% RH`
- Low power consumption
- Suitable for weather stations and environmental monitoring
- Compatible with Arduino, ESP32, ESP8266, Raspberry Pi, and other platforms

## What Does the BME280 Measure?

The BME280 combines three environmental measurements in one sensor.

### Temperature

The BME280 measures ambient temperature over a wide operating range from **-40°C to +85°C**.

Temperature measurements can be used for:

- Environmental monitoring
- Weather stations
- IoT devices
- HVAC projects
- Data logging
- Thermal monitoring

### Relative Humidity

The integrated humidity sensor measures **relative humidity (RH)**.

The typical accuracy is approximately **±3% RH**, making the BME280 suitable for general environmental monitoring applications.

### Atmospheric Pressure

The pressure sensor measures atmospheric pressure from approximately **300 to 1100 hPa**.

Pressure measurements can also be used to estimate altitude. However, altitude calculations depend heavily on the reference sea-level pressure, so pressure alone should not be treated as an exact altitude measurement.

## BME280 I²C Address

The BME280 supports two I²C addresses:

| SDO Connection | I²C Address |
|---|---|
| GND | `0x76` |
| VDDIO | `0x77` |

This allows two BME280 sensors to share the same I²C bus when they are configured with different addresses.

If more than two BME280 sensors are required, an I²C multiplexer such as the TCA9548A can be used.

## BME280 I²C Wiring

For a typical I²C connection, connect the sensor as follows:

| BME280 | Microcontroller |
|---|---|
| VIN / VCC* | Appropriate supply voltage |
| GND | GND |
| SCL / SCK | I²C SCL |
| SDA / SDI | I²C SDA |

\* The exact power pin and allowable voltage depend on the breakout board being used.

For an Arduino Uno, the hardware I²C pins are:

| BME280 | Arduino Uno |
|---|---|
| GND | GND |
| SCL | A5 |
| SDA | A4 |

For other boards such as the ESP32, use the I²C pins configured by the board and software.

## BME280 SPI Interface

The BME280 also supports SPI communication.

For SPI, the relevant signals are:

| BME280 | SPI Function |
|---|---|
| SCK | SPI Clock |
| SDI | MOSI |
| SDO | MISO |
| CSB | Chip Select |

SPI can be useful when multiple devices are connected to the same bus or when an application requires an SPI interface instead of I²C.

## BME280 with Arduino

One of the easiest ways to use the BME280 with Arduino is the **Adafruit BME280 library**.

Install the following libraries through the Arduino IDE Library Manager:

- `Adafruit BME280 Library`
- `Adafruit Unified Sensor`

Then use the following example to read temperature, humidity, and pressure.

```cpp
#include <Wire.h>
#include <Adafruit_BME280.h>

Adafruit_BME280 bme;

void setup() {
  Serial.begin(115200);

  if (!bme.begin(0x76)) {
    Serial.println("Could not find a valid BME280 sensor!");
    while (1);
  }

  Serial.println("BME280 initialized");
}

void loop() {
  Serial.print("Temperature: ");
  Serial.print(bme.readTemperature());
  Serial.println(" °C");

  Serial.print("Humidity: ");
  Serial.print(bme.readHumidity());
  Serial.println(" %");

  Serial.print("Pressure: ");
  Serial.print(bme.readPressure() / 100.0F);
  Serial.println(" hPa");

  Serial.println();

  delay(2000);
}
```

### If the Sensor Uses Address 0x77

Some BME280 breakout boards use `0x77` as their default I²C address.

In that case, change:

```cpp
bme.begin(0x76);
```

to:

```cpp
bme.begin(0x77);
```

An I²C scanner can also be used to determine which address the sensor is responding to.

## BME280 vs. BMP280

The BME280 and BMP280 are closely related sensors, but they are not identical.

| Feature | BME280 | BMP280 |
|---|---|---|
| Temperature | Yes | Yes |
| Pressure | Yes | Yes |
| Humidity | Yes | No |
| I²C | Yes | Yes |
| SPI | Yes | Yes |

The main difference is the integrated humidity sensor.

If a project requires temperature, pressure, **and humidity**, the BME280 is the appropriate choice.

## BME280 Advantages

The main advantages of the BME280 are its combination of three environmental measurements, low power consumption, and support for both I²C and SPI.

Because temperature, humidity, and pressure are available from a single device, the BME280 can simplify hardware designs compared with using separate sensors.

## BME280 Limitations

The BME280 should not be confused with a weatherproof outdoor sensor module.

The sensor measures environmental conditions but does not automatically provide protection against water, condensation, dust, or other environmental hazards.

The accuracy of altitude calculations also depends on the reference atmospheric pressure used by the software.

For production applications, the characteristics of the specific breakout board, enclosure, power supply, and surrounding environment should be considered.

## Troubleshooting

### BME280 Not Detected

If the BME280 is not detected:

1. Check the power supply.
2. Check that GND is connected correctly.
3. Verify the SDA and SCL connections.
4. Run an I²C scanner.
5. Try address `0x76`.
6. Try address `0x77`.
7. Check whether the breakout board requires a specific voltage.
8. Verify that the module is actually a BME280 and not a BMP280.

### I²C Address Is Different

If an I²C scanner reports `0x77` instead of `0x76`, initialize the library with:

```cpp
bme.begin(0x77);
```

The address is determined by the SDO connection.

### BME280 Gives Unexpected Humidity Readings

Make sure the sensor is not enclosed in a way that prevents exposure to the surrounding air.

Heat generated by nearby electronics can also affect environmental measurements.

For accurate environmental monitoring, sensor placement and airflow are important.

### Altitude Is Not Accurate

Altitude calculated from barometric pressure is strongly dependent on the reference sea-level pressure.

For better results, use an up-to-date local sea-level pressure value rather than assuming a fixed standard atmospheric pressure.

## BME280 Pinout

Typical BME280 breakout boards expose some or all of the following pins:

| Pin | Function |
|---|---|
| VCC / VIN | Power |
| GND | Ground |
| SCL / SCK | I²C Clock / SPI Clock |
| SDA / SDI | I²C Data / SPI MOSI |
| SDO | SPI MISO / I²C Address Selection |
| CS / CSB | SPI Chip Select |

Pin names and available pins vary between breakout board manufacturers.

## BME280 for Arduino and ESP32

The BME280 is particularly useful with Arduino and ESP32 because it requires only a small number of connections when using I²C.

A single I²C bus can also be shared with other compatible sensors and displays, provided that their addresses do not conflict.

When multiple BME280 sensors are required, the two available addresses (`0x76` and `0x77`) allow two devices to be used directly on the same I²C bus. Additional devices require an appropriate solution such as an I²C multiplexer.

## Frequently Asked Questions

### Is the BME280 better than the BMP280?

For applications requiring humidity measurement, yes. The BME280 includes humidity sensing while the BMP280 measures only temperature and pressure.

### What is the default BME280 I²C address?

The BME280 supports `0x76` and `0x77`. The actual address depends on the SDO connection and, for breakout boards, the board configuration.

### Can the BME280 measure altitude?

Yes, altitude can be estimated from atmospheric pressure. However, the result depends on the reference sea-level pressure and changing weather conditions.

### Can the BME280 use SPI?

Yes. The BME280 supports both I²C and SPI communication.

### Can I use two BME280 sensors on the same I²C bus?

Yes. Configure one sensor at `0x76` and the other at `0x77`. More than two sensors require an additional solution such as an I²C multiplexer.

### Is the BME280 a temperature sensor?

It is more than a temperature sensor. The BME280 measures temperature, relative humidity, and atmospheric pressure.
