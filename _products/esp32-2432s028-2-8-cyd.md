## Should You Buy the 2.8-Inch ESP32 CYD?

Choose the CYD if you want an affordable board with an ESP32, 2.8-inch colour display and resistive touch on one PCB. It suits dashboards, small control panels and LVGL experiments without separate display wiring.

Choose a **[standalone ILI9341 + XPT2046 module](/products/ili9341-xpt2046-2-8-touchscreen/)** if you already have a microcontroller, or compare the **[Sunton ESP32-8048S043C](/products/sunton-esp32-8048s043c/)** for a larger 4.3-inch display and capacitive touch. Use the [ESP32 display selector](/tools/esp32-touchscreen-selector/) to compare board formats.

**Important before ordering:** CYD revisions can differ in display controller and USB connector. Confirm the exact revision and controller with the seller rather than relying on the family name alone.

The **ESP32-2432S028** is a compact **Cheap Yellow Display (CYD)** style development board combining an ESP32-WROOM controller with a 2.8-inch 240×320 TFT touchscreen. You will also see this board sold as the ESP32-2432S028R, where the "R" refers to the resistive touch version. Listings are not always consistent, so check the touch controller (XPT2046 = resistive) rather than relying on the suffix alone.

Unlike a standalone ILI9341 + XPT2046 display module, this type of board integrates the ESP32, display, touch controller and supporting hardware on a single PCB.

Independent board definitions document the ESP32-2432S028 family with ILI9341 display and XPT2046 touch, while also documenting revisions using different display controllers and USB connectors.

## ESP32-2432S028 vs ESP32-2432S028R

The 2432S028 and 2432S028R names are used for the same 2.8-inch CYD family. The "R" marks the resistive-touch version, while capacitive-touch variants of the family use a different suffix. Some documentation links the plain 2432S028 name to an ST7789 display and the "R" to ILI9341, which matches the revision differences below. Confirm the controller on your exact board.

## Important: CYD revisions vary

The **ESP32-2432S028 family is not a single hardware revision**.

Documented variants include:

- Original revision with Micro-USB
- Rev.2 with USB-C
- Rev.3 variants using an ST7789 display controller instead of ILI9341

Because of these differences, check the controller and connector on the exact board before selecting a software configuration.

The AliExpress listing we are tracking is identified as an ESP32-WROOM 2.8-inch 240×320 touchscreen board. Its exact display-controller revision is not stated clearly enough in the public listing, so Embedded Nerd does not assume a specific controller for that offer.

## ESP32-2432S028 dimensions

The board measures approximately 86 × 50 mm. Other documentation quotes slightly different figures (for example 85 × 55 × 12 mm including components), so measure your own board before designing an enclosure.

## Display and Touch

![Front view of the CYD touchscreen](/assets/images/cyd-touchscreen-front.webp)

*Front view photographed by Embedded Nerd. The visible screen content depends on the loaded firmware.*

The standard ESP32-2432S028 reference uses a 2.8-inch 240×320 TFT display and XPT2046 resistive touchscreen. The display and touchscreen use SPI, with separate buses documented for the reference board.

The most common display controller is ILI9341, but later compatible revisions can use ST7789. This matters when configuring Arduino, ESPHome, LVGL or other display libraries.

## Why this board is different from a standalone 2.8-inch module

Our standalone **ILI9341 + XPT2046** entry describes a display module that requires a separate microcontroller.

The ESP32-2432S028 integrates:

- ESP32 processing
- Wi-Fi
- Bluetooth
- TFT display
- touchscreen
- USB-to-UART
- microSD support

That makes it a complete small HMI/development board rather than just a display peripheral.

## LVGL

The 2.8-inch CYD family is used with LVGL-based interfaces, and community configurations demonstrate ESP32-2432S028 display and touch setups.

When using LVGL, the display-controller configuration must match the actual hardware revision.

## ESP32-2432S028 Pin Considerations

A documented reference configuration uses separate SPI buses for the display and touchscreen. Typical signals include:

| Function | Reference GPIO |
|---|---:|
| TFT SCK | GPIO14 |
| TFT MOSI | GPIO13 |
| TFT MISO | GPIO12 |
| TFT CS | GPIO15 |
| TFT DC | GPIO2 |
| Touch SCK | GPIO25 |
| Touch MOSI | GPIO32 |
| Touch MISO | GPIO39 |
| Touch CS | GPIO33 |
| Touch IRQ | GPIO36 |

These are **reference-board pin assignments**, not a universal pinout for every CYD revision. Verify the exact board before wiring or configuring software.

## FAQ

### Is the ESP32-2432S028 the same as the 2432S028R?

Same family; the R denotes resistive touch. Check the revision.

### Does it have capacitive touch?

This listing uses resistive touch (XPT2046). For capacitive, see the [Sunton ESP32-8048S043C](/products/sunton-esp32-8048s043c/).

### Which display controller does it use?

ILI9341 is common; some revisions use ST7789.

Approx. 86 × 50 mm.
