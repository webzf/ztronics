The **ESP32-2432S028** is a compact **Cheap Yellow Display (CYD)** style development board combining an ESP32-WROOM controller with a 2.8-inch 240×320 TFT touchscreen.

Unlike a standalone ILI9341 + XPT2046 display module, this type of board integrates the ESP32, display, touch controller and supporting hardware on a single PCB.

## Key Features

- ESP32-WROOM-32 dual-core MCU
- Up to 240 MHz CPU frequency
- 4 MB Flash
- 520 KB SRAM
- 2.8-inch 240×320 TFT display
- Resistive touchscreen
- XPT2046 touch controller
- Wi-Fi and Bluetooth
- microSD interface
- USB-to-UART programming
- LVGL-compatible projects
- Compact approximately 86 × 50 mm board

Independent board definitions document the ESP32-2432S028 family with ILI9341 display and XPT2046 touch, while also documenting revisions using different display controllers and USB connectors. citeturn0search1turn0search5

## Important: CYD revisions vary

The **ESP32-2432S028 family is not a single hardware revision**.

Documented variants include:

- Original revision with Micro-USB
- Rev.2 with USB-C
- Rev.3 variants using an ST7789 display controller instead of ILI9341

Because of these differences, check the controller and connector on the exact board before selecting a software configuration. citeturn0search1

## Display and Touch

The standard ESP32-2432S028 reference uses a 2.8-inch 240×320 TFT display and XPT2046 resistive touchscreen. The display and touchscreen use SPI, with separate buses documented for the reference board. citeturn0search2turn0search6

The most common display controller is ILI9341, but later compatible revisions can use ST7789. This matters when configuring Arduino, ESPHome, LVGL or other display libraries. citeturn0search1turn0search4

## Why this board is different from a standalone 2.8-inch module

Our standalone **ILI9341 + XPT2046** entry describes a display module that requires a separate microcontroller.

The ESP32-2432S028 integrates:

- ESP32 processing
- Wi-Fi
- Bluetooth
- TFT display
- touchscreen
- USB-to-UART
- microSD support

That makes it a complete small HMI/development board rather than just a display peripheral.

## LVGL

The 2.8-inch CYD family is used with LVGL-based interfaces, and community configurations demonstrate ESP32-2432S028 display and touch setups. citeturn0search4

When using LVGL, the display-controller configuration must match the actual hardware revision.

## ESP32-2432S028 Pin Considerations

A documented reference configuration uses separate SPI buses for the display and touchscreen. Typical signals include:

| Function | Reference GPIO |
|---|---:|
| TFT SCK | GPIO14 |
| TFT MOSI | GPIO13 |
| TFT MISO | GPIO12 |
| TFT CS | GPIO15 |
| TFT DC | GPIO2 |
| Touch SCK | GPIO25 |
| Touch MOSI | GPIO32 |
| Touch MISO | GPIO39 |
| Touch CS | GPIO33 |
| Touch IRQ | GPIO36 |

These are **reference-board pin assignments**, not a universal pinout for every CYD revision. Verify the exact board before wiring or configuring software. citeturn0search2turn0search8
