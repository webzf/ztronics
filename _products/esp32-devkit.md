## Overview

The **ESP32 DevKit V1** is one of the most popular ESP32 development boards available today. It combines a powerful dual-core processor with integrated Wi-Fi and Bluetooth, making it ideal for embedded systems, IoT, robotics and automation projects.

Designed by **Espressif**, the board is fully compatible with the Arduino IDE, PlatformIO and ESP-IDF, providing an excellent balance of performance, flexibility and affordability.

## Key Features

- Dual-core Xtensa LX6 processor
- Up to 240 MHz CPU clock
- Built-in Wi-Fi (802.11 b/g/n)
- Bluetooth Classic and BLE
- Multiple GPIO pins
- PWM, ADC and DAC
- SPI, I²C and UART interfaces
- USB programming interface
- Deep Sleep support
- Arduino IDE compatible
- PlatformIO compatible
- ESP-IDF compatible

## Typical Applications
