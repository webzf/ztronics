## ICM-42670-P

The **ICM-42670-P** is a 6-axis MEMS inertial measurement unit (IMU) from TDK InvenSense, combining a 3-axis accelerometer and a 3-axis gyroscope in a compact 2.5 × 3.0 × 0.76 mm 14-pin LGA package.

It is designed for low-power applications where battery life is important, while still providing advanced motion-detection features such as wake-on-motion, freefall detection, low-g detection, pedometer and tilt detection.

### Key Features

- 3-axis accelerometer + 3-axis gyroscope
- Ultra-low-power 6-axis operation
- 6-axis current consumption: 0.55 mA in low-noise mode
- Sleep current: 3.5 µA
- Accelerometer low-power current: 4.4 µA at 1.56 Hz
- Gyroscope ranges: ±250, ±500, ±1000 and ±2000 dps
- Accelerometer ranges: ±2, ±4, ±8 and ±16 g
- I²C, I3C and SPI interfaces
- Up to 2.25 KB FIFO
- APEX motion-processing engine
- Wake-on-motion, freefall and low-g detection
- Pedometer, tilt and significant-motion detection
- Operating temperature: −40°C to +85°C
- Supply voltage: 1.71 V to 3.6 V
- 2.5 × 3.0 × 0.76 mm, 14-pin LGA package

### Interfaces

The ICM-42670-P supports:

- I²C up to 1 MHz
- I3C up to 12.5 MHz
- SPI up to 24 MHz

This makes it suitable for microcontroller platforms where either a simple I²C connection or a higher-speed SPI interface is required.

### Motion Features

The integrated APEX motion-processing engine provides several functions without requiring all motion processing to be performed by the host MCU, including:

- Pedometer
- Tilt detection
- Low-g detection
- Freefall detection
- Wake on motion
- Significant-motion detection

### Applications

Typical applications include:

- Wearables and fitness bands
- True wireless earbuds
- Gaming controllers
- Smart home devices
- Remote controls
- Drones
- Robotics
- AR/VR devices
- IoT products

### ICM-42670-P vs MPU6050

The ICM-42670-P is a much newer IMU architecture than the popular MPU6050. It offers lower power consumption, modern I²C/I3C/SPI interfaces, integrated motion-processing features and a significantly smaller package.

For new low-power designs, it is an attractive modern alternative to the MPU6050, particularly when battery life and advanced motion detection are important.
