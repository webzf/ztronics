The **ICM-42688-P** is a high-precision 6-axis MEMS inertial measurement unit (IMU) from **TDK InvenSense**. It combines a 3-axis accelerometer and a 3-axis gyroscope in a compact 14-pin LGA package.

The sensor is designed for applications where low noise, accurate timing, and high-quality motion data are important. It supports **I²C, I3C, and SPI**, includes a 2 KB FIFO, provides high-resolution FIFO data formats, and supports an external clock input for improved timing accuracy.

With typical gyroscope noise of **2.8 mdps/√Hz** and accelerometer noise of **70 µg/√Hz**, the ICM-42688-P is particularly suited to robotics, AR/VR/XR, motion tracking, wearables, drones, and high-performance IoT applications.

## Accelerometer and Gyroscope

The ICM-42688-P combines a 3-axis accelerometer and 3-axis gyroscope.

### 3-Axis Accelerometer

The accelerometer measures linear acceleration along the X, Y, and Z axes.

Available full-scale ranges are:

- ±2g
- ±4g
- ±8g
- ±16g

The typical accelerometer noise is approximately **70 µg/√Hz**, making the device suitable for applications where low-noise acceleration measurements are important.

### 3-Axis Gyroscope

The gyroscope measures angular velocity around the three axes.

The selectable ranges are:

- ±15.6 dps
- ±31.2 dps
- ±62.5 dps
- ±125 dps
- ±250 dps
- ±500 dps
- ±1000 dps
- ±2000 dps

The typical gyroscope noise is approximately **2.8 mdps/√Hz**.

The availability of lower full-scale ranges is useful when high angular-rate measurements are not required and finer sensitivity is more important.

## High-Resolution FIFO Data

A major feature of the ICM-42688-P is its high-resolution sensor data path.

The device provides a **2 KB FIFO** and supports FIFO data formats with up to:

- 19-bit gyroscope data
- 18-bit accelerometer data

This provides more information than the standard 16-bit sensor output used by many older IMUs.

The FIFO can also help reduce the amount of direct sensor servicing required by the host MCU, which is useful when collecting continuous motion data.

## External Clock Input

The ICM-42688-P supports an external clock input designed to improve timing accuracy.

Accurate timing can be important in motion-tracking systems because variations in sampling frequency can introduce errors when integrating gyroscope measurements or combining sensor data with other time-dependent measurements.

TDK specifically positions the external clock capability as a way to reduce system-level timing sensitivity and improve orientation measurements derived from gyroscope data.

## Interfaces

The ICM-42688-P supports three digital host interfaces:

| Interface | Maximum Speed |
|---|---:|
| I²C | 1 MHz |
| I3C | 12.5 MHz |
| SPI | 24 MHz |

I²C is convenient for many microcontroller projects, while SPI can be preferable when the application requires higher-speed transfers.

I3C provides a modern higher-speed serial interface for systems designed around the I3C ecosystem.

## APEX Motion Functions

The integrated APEX motion-processing engine provides several motion-event functions.

Supported functions include:

- Pedometer
- Tilt detection
- Tap detection
- Wake on motion
- Raise to wake/sleep
- Significant-motion detection

These functions can reduce the need for continuous raw-data processing by the host microcontroller.

## Power Consumption

The ICM-42688-P is designed as a high-performance IMU while maintaining relatively low power consumption.

TDK specifies approximately **0.88 mA** typical current for 6-axis operation in low-noise mode.

The exact system power consumption depends on the selected sensor modes, output data rates, interfaces, filtering, clock configuration, and other operating conditions.

## Supply Voltage

The ICM-42688-P operates from approximately **1.71V to 3.6V**.

This makes it suitable for modern low-voltage embedded systems. When using a breakout board, always verify whether the board includes a regulator or level-shifting circuitry and follow the board manufacturer's wiring requirements.

## Package and Size

The ICM-42688-P is supplied in a compact **14-pin LGA package** measuring approximately:

**2.5 × 3.0 × 0.91 mm**

The small package is suitable for compact motion-sensing products.

For prototyping with an ESP32, Arduino, or similar development board, a breakout board is normally required because the bare LGA package is not intended for direct breadboard insertion.

## ICM-42688-P vs MPU6050

The ICM-42688-P is a significantly more advanced alternative to the older MPU6050.

Compared with the MPU6050, it provides:

- Much lower gyroscope and accelerometer noise
- I²C, I3C, and SPI interfaces
- Higher-resolution FIFO data
- External clock support
- Modern motion-processing functions
- More selectable gyroscope ranges
- Lower-voltage operation
- A much smaller package

The MPU6050 remains useful for legacy designs and simple educational projects, but the ICM-42688-P is better suited to new designs where motion-data quality and timing accuracy are important.

Both sensors are modern 6-axis IMUs from TDK InvenSense, but they target somewhat different priorities.

If battery life is the dominant requirement, the **ICM-42670-P** is the more power-focused option. If low noise, high resolution, and timing accuracy are more important, the **ICM-42688-P** is the stronger choice.

## Using the ICM-42688-P with ESP32

The ICM-42688-P can be integrated into ESP32 projects through I²C or SPI using an appropriate breakout board.

Typical applications include:

- Robotics
- Drone stabilization
- Motion controllers
- Orientation tracking
- Wearable motion sensing
- AR/VR interfaces
- High-resolution motion data logging

For higher-rate data acquisition, SPI can be preferable to I²C. For simpler projects, I²C provides a convenient two-wire digital connection.

## Calibration

Accurate motion applications should account for accelerometer and gyroscope offsets.

Calibration can be used to compensate for sensor bias and, depending on the application, scale-factor and alignment errors. Temperature effects may also need to be considered in high-accuracy systems.

The appropriate calibration procedure depends on the required accuracy and the intended application. For basic projects, estimating stationary accelerometer and gyroscope offsets can already provide a useful improvement.
