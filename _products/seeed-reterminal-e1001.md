The E1001 is the monochrome model for projects that benefit from a large, low-power display and relatively quick partial updates. It is suitable for room information, calendars, status boards and Home Assistant dashboards that change periodically.

Its partial-refresh support makes it a better fit than the color E1002 when updates need to be more frequent. The 2000mAh battery is rated by Seeed for up to three months, depending on refresh frequency and wireless activity.

## Key specifications

| Specification | Value |
| Processor | ESP32-S3 with 8MB PSRAM |
| Display | 7.5-inch monochrome ePaper |
| Resolution | 800 × 480 |
| Grayscale | 4 levels |
| Refresh | Partial refresh; approximately 2–5 seconds |
| Flash | 32MB |
| Wireless | 2.4GHz Wi-Fi and Bluetooth 5.0 |
| Battery | 2000mAh; up to 3 months claimed by Seeed |

Specifications and battery-life figures are based on Seeed Studio's published information. Actual battery runtime depends on refresh frequency, wireless activity, firmware and operating conditions.
