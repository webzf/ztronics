The E1003 combines a large 10.3-inch monochrome ePaper panel with a capacitive touchscreen. It is the interactive model in the reTerminal E Series and is a strong option for Home Assistant control panels, room dashboards and interfaces where touch input matters.

Unlike the color E1002 and E1004, the E1003 supports partial refresh. Seeed's published guidance gives approximately 2–3 seconds for partial updates. The display uses 16-level grayscale and a 1404 × 1872 resolution.

## Key specifications

| Specification | Value |
| Processor | ESP32-S3 with 8MB PSRAM |
| Display | 10.3-inch monochrome ePaper |
| Resolution | 1404 × 1872 |
| Grayscale | 16 levels |
| Touch | Capacitive touchscreen |
| Refresh | Partial refresh; approximately 2–3 seconds |
| Flash | 32MB |
| Wireless | 2.4GHz Wi-Fi and Bluetooth 5.0 |
| Battery | 3000mAh; up to 6 months claimed by Seeed |

Specifications and battery-life figures are based on Seeed Studio's published information. Actual battery runtime depends on refresh frequency, wireless activity, firmware and operating conditions.
