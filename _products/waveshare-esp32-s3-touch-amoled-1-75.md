## Is the Round ESP32-S3-Touch-AMOLED-1.75 a Good Fit?

Choose this model if your interface benefits from a **round 466×466 AMOLED screen**—for example, a compact instrument, wearable-style display or circular status interface. The round panel affects UI design, so it is not a direct substitute for a rectangular HMI screen.

| Option | Choose it when | Main trade-off |
|---|---|---|
| **ESP32-S3-Touch-AMOLED-1.75** | You want a round 466×466 AMOLED touchscreen | UI elements must suit a circular screen |
| [**ESP32-S3-Touch-AMOLED-2.16**](/products/waveshare-esp32-s3-touch-amoled-2-16/) | You prefer a square 480×480 AMOLED panel | Different screen shape and dimensions |
| [**ESP32-C6-Touch-AMOLED-1.8**](/products/waveshare-esp32-c6-touch-amoled-1-8/) | You want a compact 368×448 AMOLED board based on ESP32-C6 | Different MCU family and display resolution |
| [**ESP32-S3-Touch-LCD-4.3**](/products/waveshare-esp32-s3-touch-lcd-4-3/) | You need a larger rectangular interface | Larger board and enclosure |

Check the exact version before ordering: the standard board, the protective-case version and the GPS version have different package contents. See the [hardware versions and box contents](#hardware-versions-and-box-contents) below. Compare integrated display formats with the [ESP32 display selector](/tools/esp32-touchscreen-selector/).

## Overview

The **Waveshare ESP32-S3-Touch-AMOLED-1.75** is a compact ESP32-S3 development board with an integrated **1.75-inch round 466×466 AMOLED touchscreen**.

It combines an ESP32-S3R8 with 16MB Flash, 8MB PSRAM, capacitive touch, a 6-axis IMU, RTC, audio, TF card storage, battery support and native USB connectivity.

## Display and Touch

The board uses a **1.75-inch 466×466 round AMOLED display** with a QSPI display interface. Touch is capacitive and uses the CST9217 controller over I2C.

The display controller is CO5300. The round 466×466 format makes the board particularly suitable for compact dashboards, wearables, portable instruments and custom HMI projects.

## ESP32-S3 Platform

The board uses an **ESP32-S3R8 dual-core Xtensa LX7 processor** running up to 240 MHz, with **16MB external Flash and 8MB PSRAM**.

Native USB Type-C is available for programming and logging, while Wi-Fi and Bluetooth 5 LE provide wireless connectivity.

## Onboard Peripherals

Waveshare provides a broad set of integrated peripherals:

- QMI8658 6-axis IMU
- PCF85063 RTC
- AXP2101 power-management IC
- ES8311 audio codec
- Dual microphone input / audio capture
- Speaker connection
- TF / microSD card slot
- TCA9554 I/O expander
- 3.7V lithium-battery connector
- Battery charging and telemetry
- USB Type-C
- I2C and UART interfaces

## LVGL Projects

The integrated AMOLED, capacitive touch, PSRAM and ESP32-S3 make this board suitable for graphical interfaces built with **LVGL**. Waveshare provides Arduino IDE and ESP-IDF development resources, and its official examples include LVGL-based interfaces.

Typical applications include:

- Compact touchscreen HMIs
- Portable instruments
- IoT dashboards
- Wearable-style interfaces
- Sensor displays
- Battery-powered controllers
- Circular status displays

## Hardware Versions and Box Contents

Waveshare lists three versions of the ESP32-S3-Touch-AMOLED-1.75 family. The display and core ESP32-S3 platform are shared, but the supplied accessories and GPS hardware differ.

| Version | Waveshare SKU | Hardware difference | Officially listed box contents |
|---|---:|---|---|
| **Standard** | 31261 | Standard board, without protective case or onboard GPS module | Board ×1, 8Ω 2W speaker ×1 |
| **-B** | 31262 | Standard board supplied with a protective case | Board with case ×1, 8Ω 2W speaker ×1 |
| **-G** | 31264 | Adds an onboard LC76G GNSS module | Board ×1, 8Ω 2W speaker ×1, GNSS ceramic antenna ×1 |

All three versions retain the 1.75-inch 466×466 AMOLED touchscreen. The GPS functionality is specific to the -G version; the standard and -B versions do not list the LC76G module.

**What about the battery?** The board has a 3.7V lithium-battery connector and charging circuitry, but Waveshare’s published package lists do not include a battery in the box contents for these versions. Treat battery support and battery inclusion as two different things, and check the seller’s exact listing before ordering.

## Frequently Asked Questions

### Is the display round or square?
It is round, with a 1.75-inch AMOLED panel and a 466×466-pixel resolution.

### Does it include a battery?
The board supports a 3.7V lithium battery through its MX1.25 connector and includes charging circuitry. However, a battery is not listed in Waveshare’s published package contents for the standard, -B or -G versions. Check the seller’s exact bundle before buying.

### What is the difference between the 1.75-inch and 2.16-inch versions?
The 1.75-inch model has a round 466×466 AMOLED display. The [ESP32-S3-Touch-AMOLED-2.16](/products/waveshare-esp32-s3-touch-amoled-2-16/) has a square 480×480 AMOLED display. The choice is mainly about the physical screen shape and the interface you want to build.

### Does it support Arduino IDE and ESP-IDF?
Yes. Waveshare documents both Arduino IDE and ESP-IDF development paths and provides examples for the board.

### Can I use LVGL?
Yes. Waveshare provides LVGL-based examples for this board. Start with the matching manufacturer example so the display and touch controllers are initialized correctly.
