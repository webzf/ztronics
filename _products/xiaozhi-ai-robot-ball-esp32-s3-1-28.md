## What is the XiaoZhi AI Robot Ball?

XiaoZhi is an open-source voice-assistant project for compatible ESP32 devices. The firmware connects the device to an AI service, allowing users to interact with a voice assistant. This product combines an ESP32-S3 board with a small round display intended to show the assistant's face and status.

The exact hardware model matters when choosing firmware. The current XiaoZhi supported-board list includes the **Spotpear ESP32-S3-1.28-BOX**. However, the seller's product name alone does not prove that every XiaoZhi AI Robot Ball listing is that exact board. Check the PCB marking, seller documentation and board revision before flashing firmware.

## XiaoZhi firmware and board compatibility

The XiaoZhi firmware is open source and its official repository is [78/xiaozhi-esp32 on GitHub](https://github.com/78/xiaozhi-esp32). The project publishes firmware for a range of ESP32 boards, but firmware images are board-specific.

The current supported-board catalogue lists the **Spotpear ESP32-S3-1.28-BOX**. Before flashing, confirm that the board you receive matches that model and revision. Do not select firmware solely because the product has an ESP32-S3 and a 1.28-inch round display. If the board identity differs, consult the XiaoZhi documentation or seller before proceeding.

- [XiaoZhi supported boards](https://xiaozhi.dev/en/docs/usage/supported-boards/)

### Does the XiaoZhi AI Robot Ball have a touchscreen?

Only the touch versions include touch input. The No-Touch versions have the round display without touch functionality.

### Does it have a built-in battery?
