How to Calibrate the MPU6050 Accelerometer and Gyroscope

Reduce sensor offset before using your MPU6050 in a balancing robot, motion logger or orientation project. This guide explains the practical workflow and what calibration can—and cannot—fix.

Why calibrate the MPU6050?

The MPU6050 combines a three-axis accelerometer and a three-axis gyroscope. Small sensor offsets can cause a stationary device to report rotation or a tilted angle. Calibration estimates these offsets so software can compensate for them.

Calibration does not eliminate all noise, temperature drift or mechanical vibration. For better results, mount the board firmly and repeat measurements after major temperature changes.

Wiring and setup

Connect the module over I²C. Many breakout boards accept 3.3 V or 5 V on their power input because they include a regulator, but this varies by module. Check your board before connecting it.

Measure the offsets

  1. Place the sensor on a stable, level surface.
  2. Wait for the board to stop moving.
  3. Collect several hundred samples from each axis.
  4. Average the readings and store the resulting offsets.
  5. For the accelerometer, account for gravity on the axis pointing upward.

Arduino example: average stationary readings

This short pseudocode-style example illustrates the averaging loop. The actual register-reading functions depend on the library you choose.

const int samples = 500;
long sumX = 0, sumY = 0, sumZ = 0;

for (int i = 0; i < samples; i++) {
  readAccelerometer(ax, ay, az);
  sumX += ax;
  sumY += ay;
  sumZ += az;
  delay(3);
}

float offsetX = (float)sumX / samples;
float offsetY = (float)sumY / samples;
// Adjust the vertical axis for gravity.
float offsetZ = (float)sumZ / samples - oneG;
Important: oneG depends on the library's units and accelerometer range. Do not copy offsets between boards without verifying the sensor configuration.

Verify the result

After applying offsets, leave the module still and inspect the output. Gyroscope readings should be close to zero on all axes; the accelerometer should show approximately 1 g on the vertical axis and near zero on the other two axes.

Troubleshooting

Readings still drift

Increase the sample count, isolate vibration and let the sensor reach a stable temperature. Offset calibration cannot remove random noise or all temperature-dependent bias.

One axis is far from expected

Check the sensor orientation, units, full-scale range and whether the library already applies calibration. Avoid subtracting the same offset twice.
